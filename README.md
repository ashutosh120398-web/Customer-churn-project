# Customer-churn-project
Analysed 7,043 telecom customers to find why they churn (26.5% rate). Used Python (Pandas, Seaborn, Scikit-learn) for cleaning and EDA, finding month-to-month contracts, short tenure, fibre internet and electronic-check payments as top drivers. Built a Random Forest model (ROC-AUC 0.84) that captures 51% of churners in the top 20% risk group.
